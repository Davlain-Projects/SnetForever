Usage: claude [options] [command] [prompt]

Claude Code (ayuda de muestra para las pruebas)

Options:
  --model <model>              Model for the current session
  --output-format <format>     Output format (only works with --print)
  --tools <tools...>           Specify the list of available tools
  --strict-mcp-config          Only use MCP servers from --mcp-config
  --mcp-config <configs...>    Load MCP servers from JSON files or strings
  --setting-sources <sources>  Comma-separated list of setting sources to load
  --no-session-persistence     Disable session persistence
  --max-turns <n>              Maximum number of agentic turns
  --effort <level>             Effort level for the current session
  --disable-slash-commands     Disable all skills and commands
  --system-prompt-file <file>  Read the system prompt from a file
  -h, --help                   Display help for command

Commands:
  auth                         Manage authentication
