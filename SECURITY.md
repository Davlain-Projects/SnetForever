# Security policy

Report a suspected vulnerability in SnetForever through [GitHub private vulnerability reporting](https://github.com/Davlain-Projects/SnetForever/security/advisories/new). Keep details within the private report while maintainers investigate and coordinate disclosure.

Include the affected component and version or commit, the expected and observed behavior, the potential impact, and the steps needed to reproduce it with test data. Redact credentials, signing material, character names, private guides, and personal data from attachments and logs.

Use the [public issue forms](https://github.com/Davlain-Projects/SnetForever/issues/new/choose) for ordinary bugs and feature proposals.
